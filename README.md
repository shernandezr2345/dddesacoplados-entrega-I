# DDD - Hogar de los Alpes

Repositorio correspondiente a la Entrega 1 del curso
Construcción de Aplicaciones No Monolíticas.

## Caso de estudio

Hogar de los Alpes.

## Objetivo

Realizar el análisis estratégico del dominio utilizando
Domain-Driven Design (DDD).

## Herramientas

- GitHub Codespaces
- Visual Studio Code
- ContextMapper
- Context Mapper Language (CML)

## Proceso

1. Entendimiento del negocio
2. Identificación de dominios y subdominios
3. Clasificación de subdominios
4. EventStorming
5. Identificación de Bounded Contexts
6. Context Mapping
7. Diseño TO-BE
